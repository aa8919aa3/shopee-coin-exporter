# 🪙 蝦皮蝦幣歷史紀錄收集與統計分析器 (Shopee Coin Collector & Analyzer)

一個專為蝦皮購物（Shopee Taiwan）開發的 Chrome 擴充功能。可在 `https://shopee.tw/user/coin/list/?type=all` 頁面中自動搜集使用者所有的蝦幣獲得與折抵紀錄，並提供統計儀表板、互動圖表以及 CSV / TXT 報表匯出功能。

目前版本：**v1.3.0**

---

## ✨ 主要功能特點

1. **自動搜集蝦幣紀錄**
   - 自動透過蝦皮目前使用的 API 逐步分頁讀取可取得的蝦幣歷史紀錄。
   - 同步讀取官方帳戶摘要，顯示目前可用蝦幣與最近到期蝦幣。
   - 支援可取消請求、單頁逾時、429/5xx 重試退避、分頁異常防護與 DOM 頁面備援。
   - 明確區分完整、部分、已停止與失敗結果，部分資料不會再被標示為完整成功。
   - 自動去重、依時間倒序排列。

2. **多維度數據彙總與統計**
   - **官方帳戶指標**：目前可用蝦幣、最近到期金額與日期。
   - **交易期間指標**：可取得期間的累積獲得、累積折抵/使用、累積過期、期間淨變動與總紀錄筆數。
   - 儀表板會標示交易 API 實際涵蓋期間，避免將期間淨變動誤認為目前可用餘額。
   - 金額以 API 最小單位整數累計，避免大量小數交易造成 IEEE-754 浮點尾差。
   - 完整抓取時會顯示「官方餘額 = 推估期初餘額 + 期間淨變動」的對帳關係。
   - **分類引擎 2.0**：先依交易方向與訂單編號判斷結構，再使用 API 原始名稱與 reason 套用強規則，避免商品名稱中的「直播／遊戲」造成活動誤判。
   - **來源分類**：支援每日簽到、每日登入、購物／訂單、退款／沖正、蝦皮遊戲、短影音、蝦皮直播、評價、VIP 訂閱、蝦皮聯名卡、蝦幣獎勵、行銷活動／任務及其他來源。
   - **使用分類**：支援訂單蝦幣折抵、票券／服務兌換、一般消費折抵、活動消耗、蝦幣過期及其他使用。
   - 跨紀錄以「相同訂單編號且相同金額」優先、「相同標題且相同金額」為備援，辨識退款或沖正；不同金額的正向訂單紀錄保留為購物回饋，並為每筆紀錄保存規則 ID、信心與分類說明。

3. **視覺化統計圖表**
   - **月份趨勢長條圖 (Bar Chart)**：展示近幾個月獲得、折抵與過期的變化趨勢。
   - **蝦幣來源分類佔比 (Donut Chart)**：僅統計獲得紀錄，呈現蝦幣來源活動的佔比分布。
   - **蝦幣使用分類佔比 (Donut Chart)**：統計折抵／使用與過期紀錄，呈現蝦幣去向的佔比分布。

4. **靈活搜尋與篩選**
   - **關鍵字搜尋**：可搜尋說明文字、訂單編號或活動名稱。
   - **類型篩選**：僅看「獲得」、「折抵/使用」或「過期」。
   - **類別篩選**：可指定單一活動分類檢視。
   - **分頁控制**：支援自訂每頁顯示筆數 (15/30/50/100 筆)。

5. **一鍵報表導出 (Export)**
   - **CSV 導出**：包含 UTF-8 BOM 標頭（`\uFEFF`），確保在 Windows / Mac Microsoft Excel 中開啟不會出現簡體/繁體亂碼。
   - 文字欄位會中和試算表公式注入，金額欄維持可加總的純數值格式。
   - **TXT 導出**：包含官方餘額、最近到期資訊、交易涵蓋期間與期間淨變動說明。
   - 匯出使用不可變資料快照及分批序列化，篩選後摘要與明細保持相同範圍。

6. **大型資料效能**
   - 表格只渲染目前頁面的 15 至 100 列，圖表只使用月份與分類摘要。
   - 中文關鍵字採低配置快速篩選；未設定篩選時直接重用來源陣列。
   - CSV／TXT 以 UTF-8 位元組分批編碼，降低上萬筆報表的 JavaScript heap 峰值。
   - 內附 10,000、50,000 與 100,000 筆的可重現時間與記憶體基準工具。

7. **Debug 與 API 性能診斷**
   - 儀表板標頭提供 `🛠 Debug` 開關，並將設定保存在瀏覽器本機儲存空間。
   - 診斷面板顯示總耗時、摘要 API 耗時、分頁數、平均每頁耗時與最近請求事件。
   - 也可在網址加上 `shopee_coin_debug=1` 查詢參數後重新載入，直接啟用 Debug 模式。
   - 分類品質面板顯示其他來源／其他使用的筆數、金額占比、低信心分類及退款配對數；占比超過 5% 時提示檢視。
   - 點擊分類環狀圖扇區或圖例可直接套用分類篩選並下鑽到交易明細。

## 📦 安裝說明 (Chrome / Edge 瀏覽器)

由於本擴充功能為開發者模式專用包，請依照以下步驟安裝：

1. **下載並解排專案 ZIP 檔**
   - 下載 `shopee-coin-exporter.zip` 並解壓縮至電腦任意資料夾中。

2. **開啟 Chrome 擴充功能管理頁面**
   - 在 Chrome 網址列輸入 `chrome://extensions/` 並按下 Enter。
   - （Edge 瀏覽器請輸入 `edge://extensions/`）。

3. **啟用「開發者模式」**
   - 在擴充功能管理頁面的右上方（或左側），開啟 **「開發者模式」(Developer mode)** 開關。

4. **載入擴充功能**
   - 點擊左上角的 **「載入未打包擴充功能」(Load unpacked)** 按鈕。
   - 選擇剛剛解壓縮的 `shopee-coin-exporter` 資料夾。

5. **安裝完成**
   - 擴充功能清單中出現「蝦皮蝦幣歷史紀錄收集與統計分析器」即表示安裝成功！

## 🚀 使用教學

1. **開啟蝦皮蝦幣紀錄頁面**
   - 開啟瀏覽器前往 [蝦皮蝦幣紀錄頁面](https://shopee.tw/user/coin/list/?type=all)。

2. **開啟分析儀表板**
   - **方式 A**：點擊頁面右下角的浮動按鈕 `🪙 蝦幣紀錄統計分析`。
   - **方式 B**：點擊 Chrome 工具列的擴充功能圖示，然後點擊「🚀 開啟分析儀表板」。

3. **讀取與分析資料**
   - 儀表板開啟後，系統會自動開始抓取蝦幣紀錄，並實時更新抓取進度。
   - 抓取完成後即可在儀表板查看統計指標、趨勢圖表與詳細紀錄列表。

4. **需要偵錯時開啟 Debug 模式**
   - 點擊儀表板標頭的 **「🛠 Debug」**，即可查看 API 與性能診斷面板。
   - Debug 模式會記錄請求端點、分頁 offset、HTTP 狀態、耗時與重試次數，但不會上傳資料。

5. **匯出資料**
   - 點擊右上角的 **「📥 匯出 CSV」** 可下載 `.csv` 試算表檔案。
   - 點擊 **「📄 匯出 TXT 報表」** 可下載完整格式化文字報表。
   - CSV／TXT 會包含分類規則、信心與說明；「分類診斷 JSON」只輸出聚合統計，不包含商品標題與訂單編號。

## 📁 專案檔案結構

```
shopee-coin-exporter/
├── manifest.json       # Chrome Manifest V3 設定檔
├── content.js          # Content script 入口點
├── classification.js   # v1.3.0 來源／使用分流分類與退款配對引擎
├── api.js              # 蝦皮 API 資料抓取與規範化模組
├── filters.js          # 大型紀錄關鍵字、類型與活動分類篩選
├── exporter.js         # CSV (UTF-8 BOM) 與 TXT 報表匯出模組
├── charts.js           # SVG/Canvas 純手繪互動圖表渲染模組
├── ui.js               # 儀表板 Modal 與 Floating Panel UI 控制器
├── styles.css          # 儀表板與圖表 CSS 樣式
├── popup.html          # Extension 工具列彈出選單 HTML
├── popup.js            # Extension 工具列彈出選單 JS
├── tests.js            # 核心回歸、六分類與 100,000 筆篩選測試
├── tests/fixtures/     # 去識別化分類回歸案例
├── benchmark.js        # 10,000 至 100,000 筆時間與記憶體基準
├── benchmark-compare.js # 優化前後基準比較工具
├── PERFORMANCE_REPORT.md # 大型資料效能與記憶體分析報告
├── icons/              # 圖示資源檔 (16x16, 48x48, 128x128)
└── README.md           # 說明文件
```

## 🔒 隱私與安全性聲明

- 本擴充功能完全於 **本機客戶端 (Local Browser)** 執行，所有抓取的蝦幣紀錄均儲存於瀏覽器記憶體中，**絕不**上傳至任何第三方伺服器。
- 本工具僅讀取您已登入之蝦皮帳號的蝦幣紀錄，不會儲存任何帳號密碼或個人敏感資料。
