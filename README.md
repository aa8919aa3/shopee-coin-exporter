# 🪙 蝦皮蝦幣歷史紀錄收集與統計分析器 (Shopee Coin Collector & Analyzer)

一個專為蝦皮購物（Shopee Taiwan）開發的 Chrome 擴充功能。可在 `https://shopee.tw/user/coin/list/?type=all` 頁面中自動搜集使用者所有的蝦幣獲得與折抵紀錄，並提供統計儀表板、互動圖表以及 CSV / TXT 報表匯出功能。

目前版本：**v1.1.0**

---

## ✨ 主要功能特點

1. **自動搜集蝦幣紀錄**
   - 自動透過蝦皮目前使用的 API 逐步分頁讀取可取得的蝦幣歷史紀錄。
   - 同步讀取官方帳戶摘要，顯示目前可用蝦幣與最近到期蝦幣。
   - 支援 DOM 頁面動態解析備援機制，確保資料讀取穩定。
   - 自動去重、依時間倒序排列。

2. **多維度數據彙總與統計**
   - **官方帳戶指標**：目前可用蝦幣、最近到期金額與日期。
   - **交易期間指標**：可取得期間的累積獲得、累積折抵/使用、期間淨變動與總紀錄筆數。
   - 儀表板會標示交易 API 實際涵蓋期間，避免將期間淨變動誤認為目前可用餘額。
   - **自動分類與標籤**：自動識別「每日簽到」、「購物/訂單」、「消費折抵」、「蝦皮遊戲」、「行銷活動/任務」、「退款/補償」等類別。

3. **視覺化統計圖表**
   - **月份趨勢長條圖 (Bar Chart)**：展示近幾個月獲得(+)與折抵(-)的變化趨勢。
   - **來源與消耗分類環狀圖 (Donut Chart)**：清晰呈現各活動類別的佔比分布。

4. **靈活搜尋與篩選**
   - **關鍵字搜尋**：可搜尋說明文字、訂單編號或活動名稱。
   - **類型篩選**：僅看「獲得」、「折抵/使用」或「過期」。
   - **類別篩選**：可指定單一活動分類檢視。
   - **分頁控制**：支援自訂每頁顯示筆數 (15/30/50/100 筆)。

5. **一鍵報表導出 (Export)**
   - **CSV 導出**：包含 UTF-8 BOM 標頭（`\uFEFF`），確保在 Windows / Mac Microsoft Excel 中開啟不會出現簡體/繁體亂碼。
   - **TXT 導出**：包含官方餘額、最近到期資訊、交易涵蓋期間與期間淨變動說明。

## 📦 安裝說明 (Chrome / Edge 瀏覽器)

由於本擴充功能為開發者模式專用包，請依照以下步驟安裝：

1. **下載並解排專案 ZIP 檔**
   - 下載 `shopee-coin-exporter.zip` 並解壓縮至電腦任意資料夾中。

2. **開啟 Chrome 擴充功能管理頁面**
   - 在 Chrome 網址列輸入 `chrome://extensions/` 並按下 Enter。
   - （Edge 瀏覽器請輸入 `edge://extensions/`）。

3. **啟用「開發者模式」**
   - 在擴充功能管理頁面的右上方（或左側），開啟 **「開發者模式」(Developer mode)** 開關。

4. **載入擴充功能**
   - 點擊左上角的 **「載入未打包擴充功能」(Load unpacked)** 按鈕。
   - 選擇剛剛解壓縮的 `shopee-coin-exporter` 資料夾。

5. **安裝完成**
   - 擴充功能清單中出現「蝦皮蝦幣歷史紀錄收集與統計分析器」即表示安裝成功！

## 🚀 使用教學

1. **開啟蝦皮蝦幣紀錄頁面**
   - 開啟瀏覽器前往 [蝦皮蝦幣紀錄頁面](https://shopee.tw/user/coin/list/?type=all)。

2. **開啟分析儀表板**
   - **方式 A**：點擊頁面右下角的浮動按鈕 `🪙 蝦幣紀錄統計分析`。
   - **方式 B**：點擊 Chrome 工具列的擴充功能圖示，然後點擊「🚀 開啟分析儀表板」。

3. **讀取與分析資料**
   - 儀表板開啟後，系統會自動開始抓取蝦幣紀錄，並實時更新抓取進度。
   - 抓取完成後即可在儀表板查看統計指標、趨勢圖表與詳細紀錄列表。

4. **匯出資料**
   - 點擊右上角的 **「📥 匯出 CSV」** 可下載 `.csv` 試算表檔案。
   - 點擊 **「📄 匯出 TXT 報表」** 可下載完整格式化文字報表。

## 🔒 隱私與安全性聲明

- 本擴充功能完全於 **本機客戶端 (Local Browser)** 執行，所有抓取的蝦幣紀錄均儲存於瀏覽器記憶體中，**絕不**上傳至任何第三方伺服器。
- 本工具僅讀取您已登入之蝦皮帳號的蝦幣紀錄，不會儲存任何帳號密碼或個人敏感資料。
